# Movie Watchlist starter (SOF2216, Weeks 2 and 3 workshop)

ACBT · SOF2216 Web Application Development

A small React app you will build up task by task during the workshop. Follow the task sheet (PDF). Every place you must change has a comment starting with `TASK` and a number. In VS Code press Ctrl+Shift+F and search for `TASK 3`, for example.

## Run it

```bash
node --version      # must be v22.22 or higher
npm install
npm run dev         # open the address it prints, usually http://localhost:5173
```

Start with Git so you can commit after every task:

```bash
git init
git add .
git commit -m "Starter"
```

## Tasks

| # | Task | Week |

## Check your understanding

Every task ends with questions. Answer them in your own words in `ANSWERS.md`. Running code is not the same as understanding it.

## Rules

- Type the code yourself. You must be able to explain every line.
- This is practice. Your Sprint 1 assignment is separate: use your own API and your own design.
- Movie titles in `public/movies.json` are fictional sample data.
